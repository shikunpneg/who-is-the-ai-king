🚀 3 步上线（0 月成本）

  1. Supabase 建项目：supabase.com → New Project → 复制 URL + Service Key；SQL Editor 粘贴运行 supabase/schema.sql
  2. Vercel 导入：vercel.com → New Project → Import shikunpneg/who-is-the-ai-king → 配环境变量 SUPABASE_URL / SUPABASE_KEY → Deploy
  3. 启用 GitHub Actions cron：仓库 Settings → Secrets and variables → Actions → 配同样的两个密钥
完整复现命令：

# 1. clone
git clone https://github.com/shikunpneg/who-is-the-ai-king
cd who-is-the-ai-king

# 2. install
npm install

# 3. 本地跑（用 seed 数据，无数据库）
npm run dev   # 打开 http://localhost:3000

# 4. 手动跑一次 cron
npm run cron
