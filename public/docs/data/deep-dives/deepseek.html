2.2 V4 四大核心架构创新（55 页技术报告）

  1. 混合注意力架构：DSA2（DeepSeek Attention 2）整合 V3/R1 的 DSA 设计 + 引入 2026 年初的 NSA（Native Sparse Attention）稀疏注意力方案
  2. Mega MoE 内核：每层 384 个专家，每次激活 6 个 + 1 个共享专家
  3. 流形约束超连接（mHC / Hyper-Connections）：缓解深层网络的梯度传播问题
  4. Muon 优化器 + FP4 量化感知训练：MoE 专家参数采用 FP4，其余大部分 FP8；训练效率极大提升

三、算力底座：迁移到华为昇腾

3.1 从英伟达到华为的关键迁移

  1. R1 时代：对英伟达 GPU 的 PTX 底层做了极致优化，是「花小钱办大事」的核心
  2. V4 时代：整套系统从英伟达 CUDA 生态迁到华为昇腾 CANN，所有底层代码、调度逻辑、工程体系要重写
  3. 原因：英伟达 H200 对华禁运；DeepSeek 主动选择「主权算力」路线
  4. 挑战：昇腾在内存带宽、芯片互联、KV Cache 管理的成熟度与英伟达有差距；CANN 算子覆盖、自动并行不如 CUDA
  5. 结果：V4 Pro 面向华为昇腾；V4 Flash 可在其他国产芯片上跑
  6. 代价：V4 原计划 2-3 月发布，延至 4 月 24 日
📌 战略意义：「首个完全在国产芯片上运行的前沿大模型」——华为 CANN 官方账号为此开了直播站台。这是中美 AI 脱钩下中国 AI 自主可控的关键里程碑[$TRAE_REF](https://cloud.tencent.com.cn/developer/article/2662161)。

六、公司战略

6.1 战略关键词：架构创新优先 + 极致开源 + 算力主权

  1. 不盲目堆参数：用架构创新（MLA / DSA / NSA / MoE / FP4）换效率，而非靠参数规模
  2. 全栈 MIT 开源：V1-V4 全系 MIT 协议；技术报告 55-79 页公开
  3. 价格战：V4-Flash 输出 0.28 美元/百万 token = OpenAI 1/5；海外开发者实测同等任务成本从 $35 降至 $0.31
  4. 算力主权：从英伟达迁到华为昇腾；为国家 AI 自主可控做兜底
  5. 不依赖 IPO / 商业化：早期「短期不融资」；近期涨价或与算力成本上升有关

6.3 风险与挑战

  • 算力受限：V4 迁昇腾后性能与英伟达仍有差距；后续模型迭代速度可能受影响
  • 涨价压力：2026-08 API 全线涨价，对中小开发者粘性构成威胁
  • 团队稳定性：梁文锋本人承认「融资后大家期权多，最大风险是团队稳定」
  • 国际化挑战：美方监管持续收紧；欧盟 GDPR / 印度 / 东南亚合规成本上升
  • 开源生态两面性：开源带来生态但难形成护城河；易被大厂快速复制
