六、公司战略

6.1 战略关键词：嵌入 + 全模态 + 极致性价比

  1. 嵌入字节全产品：将 AI 能力下沉到抖音 / 今日头条 / 飞书 / 即梦 / 剪映等 10+ 个亿级产品；不依赖独立 C 端
  2. 全模态矩阵：语言 + 视觉 + 视频 + 图像 + 语音 + 音乐 + 向量共 7 大类 20+ 个模型；为不同场景提供最适配 SKU
  3. 极致 token 价：Seed 2.1 Pro 输入 6 元/百万 = Claude Opus 4.6 的 1/5；Seed 2.0-Mini 输入 0.2 元/百万 = 行业最低
  4. 流量 + 企业 + 硬件三引擎：C 端 App 走量 / B 端 MaaS 走 API / 智能体平台 + 智能眼镜等多端入口

6.2 战略五大阵营（公司战略维度）

维度字节豆包 / Seed 打法
开源 / 闭源完全闭源（参数、训练数据全部不公开）
目标客户C 端（豆包 App）+ B 端（火山引擎）+ 字节全系嵌入
核心壁垒字节系 10+ 亿级 App 流量 + 数据闭环 + 工程优化
商业模式API 按量 + 专业版订阅 + 广告 / 电商接入
国际化通过 TikTok 间接覆盖海外；豆包本身未主推海外

6.3 风险与挑战

  • 闭源压力：完全不开放权重，难以吸引研究社区和独立开发者（与 DeepSeek / GLM / Qwen 路线相反）
  • C 端付费转型阵痛：2026-05 付费后 MAU 流失 1173 万（豆包 + 元宝 + Kimi 三家合计）
  • 海外封锁：中美科技摩擦下，对外商业化渠道受限
  • 开源阵营竞争：DeepSeek V4-Flash 输出价 0.28 美元/百万 token = 豆包的一半；开源 + 极低价双重压力
